# Sat Help - conectando vidas 🛰️

Projeto desenvolvido para a Global Solution do primeiro ano da Graduação de Engenharia de Software da Fiap. O programa tem como objetivo desenvolver uma solução de telemedicina focada em situações de emergência, quando a infraestrutura cai.

## 🌍 Funcionalidades
Após enchentes, deslizamentos ou apagões, pessoas ficam sem internet. O SatHelp usa conexão via satélite para permitir que vítimas:
- relatem sintomas
- enviem localização
- recebam triagem automática
